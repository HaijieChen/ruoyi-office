# 加班跨天与节假日日历 白盒用例

主题：`oa-overtime-crossday-fix-20260906`（邮件 #41 + #49）
时区：Asia/Shanghai。权威：后端强校验；前端预览与提示对齐，不可替代后端。
不发布生产。基线工作区：`.worktrees/fix-oa-overtime-crossday`，已同步 test `dc3b27f3a`。

## 确定规则

1. 按自然日拆分实际覆盖区间。结束恰好 00:00 不产生下一日零时长切片。
2. 单次申请合计 ≥ 2 小时；日片段不必各满 2 小时。跨午夜 1+1 允许，但涉及日期都必须可申请。
3. 每个自然日最多计 8 小时（单日原始区间 >8 按 8 计）。同一申请人同一天多次申请累计 ≤8。占用状态：RUNNING + APPROVE。撤回/驳回/取消释放。并发用申请人+日行锁。
4. 已有跨天行的 `hours` 是申请合计；占用按 `hoursOnDay(start,end,day)` 拆到各日，不得把合计整段算进某一天。
5. 可申请日 = **法定节假日** 或 **普通周末（周六日且非调休上班）**。调休休息的工作日 **不扩大** 为可申请。非周末且非法定期，整单拒绝并列出具体日期，不得静默跳过。
6. `holiday=true` 要求覆盖日全部为法定节假日；`holiday=false` 要求覆盖日全部为普通周末。混合法定+周末整单拒绝（审批链一致）。
7. 业务提交只读本地 **已核验且 ACTIVE** 日历，不访问外网。缺年/未生效提示「该年度节假日日历尚未发布或配置，请联系人事」。
8. 截图 2026-09-06 09:00–2026-09-08 19:00 含工作日，必须拒绝，不得按 24h 可提交验收。

## 2026 四类日期（国办发明电〔2025〕7号）

来源：https://www.gov.cn/zhengce/zhengceku/202511/content_7047091.htm  
法定日依据：《全国年节及纪念日放假办法》——元旦 1 天、春节除夕至初三 4 天、清明 1 天、劳动节 3 天、端午 1 天、中秋 1 天、国庆 3 天。连休中的调休休息日 **不是** 法定节假日。

| 类型 | 含义 | 可申请 | 2026 示例 |
|---|---|---|---|
| LEGAL_HOLIDAY | 法定节假日（全年 13 天） | 是（holiday=true） | 01-01；02-16..19；04-04；05-01..02；06-19；09-25；10-01..03。05-03 是周日普通周末 |
| WEEKEND | 周六日且非补班、非法定 | 是（holiday=false） | 09-05、09-06；01-03；02-15；04-05；10-04 |
| MAKEUP_WORKDAY | 调休上班 | 否 | 01-04、02-14、02-28、05-09、09-20、10-10 |
| MAKEUP_REST | 工作日调休休息 | 否 | 01-02、02-20、02-23、04-06、05-04、05-05、10-05..07 |
| WEEKDAY | 普通工作日 | 否 | 09-07、09-08 |

分类优先级：法定 > 补班 > 调休休息 > 周末(六日) > 工作日。

## 错误码

| 码 | 文案 |
|---|---|
| 1_009_001_014 TOO_SHORT | 加班时长不能少于 2 小时 |
| 1_009_001_015 DAY_QUOTA_EXCEEDED | 当天加班合计不能超过 8 小时 |
| 1_009_001_016 停用同日限制 | 不再抛出「必须为同一自然日」 |
| 1_009_001_020 WORKDAY_FORBIDDEN | 以下日期不是周末或法定节假日，不能申请加班：{} |
| 1_009_001_021 CALENDAR_MISSING | 该年度节假日日历尚未发布或配置，请联系人事 |
| 1_009_001_022 DAY_TYPE_MISMATCH | 加班类型与日期不一致：法定节假日请选「是」，普通周末请选「否」 |

## 日历运维

- 首次部署：核验后的 2026 JSON 写入 ACTIVE 版本（含来源 URL、文号、抓取/导入时间、content_hash、核验状态）。
- Job：`oaOvertimeCalendarFetchJob`，XXL + `infra_job` 注册。cron 每周一 09:00 Asia/Shanghai；处理器内：10–12 月抓当年+次年，其余月仅当月第一周抓已生效年更正。
- 允许来源 host：`www.gov.cn`。超时、有限重试。原始 HTML 入库。不编造政府 API。
- 仅 `bpm:oa-overtime-calendar:verify`（hr_admin/super_admin）可启用。申请人无启用权。
- 通知模板 `bpm_oa_overtime_calendar`：失败/待核验/未发布；fingerprint 去重。

## 非目标

不放宽原审批链、余额、2h/8h、重叠、并发锁。不把连休全部标成法定。不发布生产。
