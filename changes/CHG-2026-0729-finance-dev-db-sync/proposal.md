# CHG-2026-0729-finance-dev-db-sync — 财务模块 dev 共享库同步与动态角色授权

- Mode: `strict`
- Created: 2026-07-29
- Status: approved

## Current behavior

`codeup/dev` 已包含完整财务前后端代码，但共享的 dev/test 数据库尚无财务表、菜单和角色。
角色迁移 SQL 还把本地数据库生成的菜单 ID（5225、5228、5229、5245）写死，无法移植到当前共享库。

## Desired behavior

财务迁移可在任意符合基线结构的数据库上重复执行，角色授权通过稳定业务键定位菜单；共享库完成迁移后，财务管理员和商务人员获得设计约定的菜单及按钮权限。

## Goals

- 移除角色迁移中的硬编码菜单 ID。
- 将修复推送到 `codeup/dev`，供云效流水线使用。
- 备份共享库的系统菜单、角色及角色菜单映射后，执行财务迁移。
- 验证迁移幂等、权限隔离和应用运行态。

## Non-goals

- 不创建财务测试用户。
- 不给现有用户分配财务角色。
- 不修改非财务业务数据，也不清理迁移备份。

## Acceptance criteria

- [x] 角色 SQL 不包含环境相关菜单 ID，并使用 `/finance`、组件路径和权限码定位。
- [x] 财务相关契约测试通过，修复提交已推送到 `codeup/dev`。
- [x] 共享库迁移前备份可用，财务 SQL 按依赖顺序成功执行。
- [x] 财务表、菜单、角色及角色菜单映射符合设计。
- [x] 全量迁移重跑后对象数量和授权集合不漂移。
- [x] 未创建测试用户，未改现有用户角色。

## Open questions

无。用户已于 2026-07-29 明确确认方案 1。
